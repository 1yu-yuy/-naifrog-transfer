HarmonyOS 5 / 6 · 系统投屏助手

整屏投到电脑，也能显示相机画面

首次使用需要 Windows 安装“无线显示器”，并且电脑硬件支持 Miracast。投屏画面会显示在 Windows 接收窗口。

1. 首次准备：点击“安装入口”，在 Windows 的“查看功能 / 添加功能”中搜索并安装“无线显示器”。
2. 点击“打开电脑投屏设置”，按页面提示允许投影，然后启动“无线显示器 / 连接”应用。
3. 手机开启 WLAN，从右上角下滑打开控制中心，选择“无线投屏”，找到这台电脑，确认连接。
4. 要显示摄像头画面：投屏连接成功后，在手机打开“相机”，切换前后摄像头即可。
这里调用 Windows 系统投屏功能。文件传输二维码仅用于发文件，不能用于整屏投屏。
如果系统提示此电脑不支持接收 Miracast，则当前电脑不能通过此方式投屏。相机是否允许镜像以手机实际表现为准，尚未完成真机验证。
相机画面显示在投屏窗口；暂不提供会议软件可选的虚拟摄像头。
